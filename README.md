# 王者荣耀·局内节奏与数值平衡性 BI 分析

## 📌 项目背景与数据说明
本项目基于腾讯 AI Lab 公开的真实王者段位对局切片数据（100 局，共 3146 条半分钟级时间切片），结合 2026 年 5 月公开版本改动记录，构建“分布基线—异常筛查—改动弹性”三层数据分析框架，旨在用数据量化 MOBA 游戏中的“滚雪球效应”及英雄数值改动带来的实际影响。

**⚠️ 数据局限性说明**：受限于公开样本规模（100局），本项目主要用于验证分析方法与 ETL 管道，暂不支撑全英雄胜率排名。

## 🛠️ 技术栈
*   **数据清洗与特征工程**：Python (Pandas)
*   **数据存储与 SQL 分析**：MySQL, SQLAlchemy
*   **BI 可视化**：Power BI Desktop

## 🧠 核心分析框架与洞察

### 1. 局内节奏与经济雪球效应
*   **分析**：统计 0-27 分钟胜方的平均经济差与击杀差变化。发现前 15 分钟是经济裂变核心期，优势方在 10-13 分钟左右达到经济差峰值（约 4000）。
*   **异常检测**：利用 SQL 窗口函数计算 10 分钟节点的经济差均值和标准差，通过 `均值 + 1.5 倍标准差` 设定动态阈值（本样本中阈值约为 8665），精准锁定 8 局“严重滚雪球局”。
*   **业务结论**：击杀差与经济差呈强正相关，验证了雪球效应的存在。建议在 10 分钟节点加强防御塔保护机制，以延缓劣势方的崩盘速度。

### 2. 版本改动弹性复盘（基于公开改版数据）
*   **分析**：将英雄削弱/加强的类型（机制、移速、数值）与实装的胜率变化进行交叉对比。
*   **业务结论**：**移速类削弱**（如沈梦溪二技能移速再砍 10%）对胜率影响极小；而**隐性机制移除**（如阿古朵本体重置球球普攻）导致巅峰赛胜率暴跌 1.1%。数值策划应警惕机制移除带来的隐性胜率失控。

## 📂 文件结构
*   `01_data_cleaning.ipynb` : 解析嵌套 JSON、展平数据并入库的 Python 代码。
*   `02_analysis.sql` : 核心的基线计算与异常筛查 SQL 代码。
*   `hok_clean_data.csv` : 清洗后的半分钟级时间切片面板数据。
*   `patch_winrate_changes.csv` : 手工整理的版本改动与胜率变化数据。
*   `hok_balance_dashboard.pbix` : Power BI 可视化监控大屏文件。
